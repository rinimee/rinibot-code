> ## *oh? you want to run her locally?*
> to run rinibot locally, make sure you have node.js of v24 or higher, git installed, and a slack workspace where you can install apps.
> ### *instructions!*
> 1. open terminal and clone project: git clone https://github.com/rinimee/rinibot-code
> 2. install npm with running --> npm install
> 3. obtain slack creds:
>    * create new app with socket mode in slack api
>    * copy the xapp token,
>    * add permissions under OAuth
>    * install to workspace and copy xoxb token as well
>    * copy signing secret from basic information tab
> 5. make .env in root directory of project and add your creds (xoxb, xapp, and signing secret) --> MUST BE INSIDE .gitignore !!
> 6. run locally using command npm run dev
> 7. and then use npm start --> should output "bot is running!"
> 8. youre all set!
